# Student Management System (Java + SQLite)

## Description
I developed a Student Management System in Java using SQLite and JDBC, implementing full CRUD operations with persistent storage.

## Features
- Register students
- View students
- Update grades
- Delete students
- Search students
- Calculate average

## Technologies Used
- Java
- JDBC (Java Database Connectivity)
- SQLite
- SQL

## Database
The system uses a SQLite database (`estudiantes.db`) to store student data persistently.
